# Combis Zempoala

Proyecto para coordinar el servicio de combis entre Zempoala (Hidalgo) y Pachuca:
la fila de salida en la base, la información de rutas y precios para el pasajero,
el tiempo estimado de la próxima unidad, y la bolsa de choferes para relevos.

> Estado: exploración. Todavía no hay código de aplicación.
